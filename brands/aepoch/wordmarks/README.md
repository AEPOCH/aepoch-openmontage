# ÆPOCH runtime identifier

These files combine the exact canonical Æ mark with live text spelling
`ÆPOCH`. No font file is embedded or distributed.

They are **provisional runtime identifiers**, not an outlined canonical
wordmark extracted from a supplied vector master. The supplied
`AEPOCH-original.svg` is complex Earth/Cosmos artwork rather than a clean
standalone outlined wordmark, and the markdown brand system does not identify
a canonical font family.

## Runtime recommendation

Prefer building the identifier directly in Remotion:

- canonical mark component
- live text `ÆPOCH`
- the approved project font already present in the repository
- sentence and capitalization rules from the brand system

Replace these provisional SVGs only when an official outlined wordmark master
is supplied. Do not convert or distribute a local font file as part of this
asset library.
