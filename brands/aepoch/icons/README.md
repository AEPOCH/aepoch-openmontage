# ÆPOCH icon family

The icon system uses the canonical product vocabulary:

- Circle: individual or state
- Ring: protocol or collective
- Arc: time or epoch boundary
- Path: relationship or flow

## Source geometry

- ViewBox: `0 0 24 24`
- Stroke: `1.6`
- Caps: round
- Joins: round
- Color: `currentColor`

Use CSS or Remotion props to assign approved semantic colors.

## Prohibited additions

Do not introduce generic:

- Gears
- Clouds
- Padlocks
- Server racks
- Crypto coins
- Price charts
- Four-pointed stars

New icons must be composed from the same circle, ring, arc, and path grammar.
