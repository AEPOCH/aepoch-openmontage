# ÆPOCH video backgrounds

All backgrounds are deterministic 1920×1080 SVG assets.

| File | Intended use |
|---|---|
| `earth-rise-light.svg` | Default human-centered and reframe background |
| `paper-clean.svg` | Clean diagrams, comparisons, and text-only scenes |
| `earth-field.svg` | Human-presence emphasis |
| `cosmos-field.svg` | Protocol and mechanism emphasis |
| `dual-pole-field.svg` | Earth/Cosmos contrast or convergence |
| `void-dark.svg` | Broken-status-quo hook scenes only |
| `depth-dark.svg` | Secondary dark contained scene |

`earth-rise-light.svg` preserves the canonical fixed pole placement:

- Earth warm: 8% W, 75% H
- Earth sand: 18% W, 92% H
- Cosmos pearl: 92% W, 4% H
- Cosmos prism: 98% W, 18% H

Do not recolor these assets into generic gradients. For animated versions,
move each pool by no more than 1.5% of frame width/height and change radius by
no more than 2%, using the timing rules in `MOTION_TOKENS.md`.
