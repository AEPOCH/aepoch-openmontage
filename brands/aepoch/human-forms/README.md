# ÆPOCH human-form family

The human-form family is deliberately symbolic and non-mascot-like.

## Canonical geometry

- Gender-neutral
- No face
- Rounded head and body
- Natural symbolic proportion rather than chibi/cartoon proportions
- No clothing or personality detail
- No person is visually larger because of wealth, holdings, or status

## State semantics

| File | Meaning |
|---|---|
| `human-neutral.svg` | A person without a protocol state |
| `human-present.svg` | Presence is visible |
| `human-active.svg` | The person is actively participating |
| `human-verified.svg` | Successful Proof of Life verification |
| `human-inactive.svg` | The person is currently inactive |
| `human-pair.svg` | Direct relationship between two people |
| `human-community.svg` | Small collective |

`human-verified.svg` is the only human asset in this family that uses Moss
`#4CAF82`. Do not reuse that treatment for generic success.

For runtime recoloring, prefer `human-neutral-currentcolor.svg`. Preserve the
canonical silhouette geometry when creating additional states.
